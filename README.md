# Сервис управления рассылками (Mailing Service)

Веб-приложение на базе фреймворка **Django** для создания, планирования, отправки и мониторинга email-рассылок клиентам. Проект реализует полный цикл работы с клиентской базой, шаблонами сообщений, журналом попыток отправки, ролевой моделью доступа и кэшированием данных.

---

## Основные возможности

### 1. Управление рассылками и контентом (приложение `mailing`)
- **Получатели рассылок (`Recipient`):** ведение базы клиентов (Email, Ф. И. О., комментарий) с привязкой к владельцу.
- **Сообщения (`Message`):** создание и редактирование шаблонов писем (тема и тело сообщения).
- **Рассылки (`Mailing`):**
  - Настройка периода активности (`start_time` и `end_time`) с валидацией временных интервалов.
  - Автоматическое динамическое определение статуса рассылки (`Создана`, `Запущена`, `Завершена`).
  - Запуск рассылки по требованию через веб-интерфейс или через консольную команду.
- **Журнал попыток (`MailingAttempt`):** фиксация каждой попытки отправки письма (дата и время, статус `Успешно` / `Не успешно`, ответ почтового сервера).
- **Главная страница:** сводная аналитика в реальном времени (общее количество рассылок, количество активных рассылок и число уникальных получателей).

### 2. Пользователи и разграничение прав доступа (приложение `users`)
- **Кастомная модель пользователя (`User`):** авторизация по `email` вместо `username`, поддержка аватара, номера телефона и страны.
- **Регистрация и безопасность:**
  - Подтверждение регистрации по электронной почте через уникальный токен активации.
  - Восстановление и сброс пароля по email.
  - Редактирование личного профиля.
- **Ролевая модель:**
  - **Авторизованный пользователь:** полный CRUD-доступ исключительно к собственным получателям, сообщениям, рассылкам и просмотр истории своих отправок.
  - **Менеджер (группа `Managers`):** просмотр всех пользователей, клиентов и рассылок сервиса; возможность блокировать/разблокировать пользователей и принудительно отключать рассылки без права их редактирования или удаления.

### 3. Производительность и кэширование
- Настроено кэширование на базе **Redis** (с возможностью переключения на локальный кэш в памяти через переменные окружения).
- Применено низкоуровневое кэширование для статистики на главной странице и кэширование представлений (`cache_page`) для списков данных.

---

## Стек технологий

- **Backend:** Python 3.13, Django 6.0
- **База данных:** PostgreSQL (`psycopg2-binary`)
- **Кэширование:** Redis (`redis`)
- **Frontend:** HTML5, Bootstrap 5 (локальные статические файлы)
- **Управление зависимостями:** Poetry
- **Конфигурация:** `python-dotenv`

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com<ВАШ_ЛОГИН>/mailing_service.git
cd mailing_service
```

### 2. Установка зависимостей через Poetry
```bash
poetry install
poetry shell
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корне проекта на основе `.env.sample` и заполните его своими параметрами:

```env
SECRET_KEY=ваш_секретный_ключ_django
DEBUG=True

# Настройки PostgreSQL
DB_NAME=mailing_service
DB_USER=postgres
DB_PASSWORD=ваш_пароль_от_бд
DB_HOST=localhost
DB_PORT=5432

# Настройки кэширования (Redis)
CACHE_ENABLED=True
REDIS_URL=redis://127.0.0.1:6379/1

# Настройки почтового сервера (SMTP)
EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465
EMAIL_USE_SSL=True
EMAIL_HOST_USER=your_email@yandex.ru
EMAIL_HOST_PASSWORD=your_app_password
```

### 4. Подготовка базы данных и ролей
Создайте пустую базу данных `mailing_service` в PostgreSQL, затем выполните миграции и инициализацию группы менеджеров:

```bash
python manage.py migrate
python manage.py create_managers_group
```

### 5. Создание администратора и запуск сервера
```bash
python manage.py createsuperuser
python manage.py runserver
```

После запуска приложение будет доступно по адресу: `http://127.0.0`, административная панель — `http://127.0.0admin/`.

## Пользовательские CLI-команды

- **Запуск всех активных рассылок из консоли** (можно использовать для планировщиков задач `cron` / Task Scheduler):
  ```bash
  python manage.py send_mailings
  ```
- **Создание группы `Managers` с правами просмотра и отключения рассылок:**
  ```bash
  python manage.py create_managers_group
  ```
